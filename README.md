**CMAQ**：Community Multiscale Air Quality（区域多尺度空气质量模型）<br>
     （1）第一代：ISC,AERMOD, CALPUFF(质量守恒、湍流扩散统计理论)<br>
     （2）第二代：光化学污染模式(UAM,CIT等)、区域尺度光化学模式(ROM)、酸沉降模式(RADM,ADOM,STEM)(在第一代基础上增加了污染物转化的机制)<br>
     （3）第三代：CMAQ，CAMx，WRF-Chem(考虑气象和大气污染的双向反馈)<br>

**（2）第二代**：<br>
- **UAM**: Urban Airshed Model (城市空气域模型，首个得到广泛应用的城市尺度光化学网格模型)<br>
- **CIT**: California Institute of Technology model (加州理工学院模型，著名的区域光化学空气质量模型)<br>
- **ROM**: Regional Oxidant Model (区域氧化剂模型，用于模拟北美地区臭氧等二次污染)<br>
- **RADM**: Regional Acid Deposition Model (区域酸沉降模型，用于模拟硫氮化合物的长距离输送与沉降)<br>
- **ADOM**: Acid Deposition and Oxidant Model (酸沉降与氧化剂模型，加拿大开发的类似系统)<br>
- **STEM**: Sulfur Transport Eulerian Model (硫输送欧拉模型，早期欧拉型区域酸沉降模型)<br>

**WRF**：Weather Research and Forecasting（天气研究与预报模型，是当前最广泛使用的中尺度数值气象预报与模拟系统）<br>
**CAMx**：Comprehensive Air Quality Model with Extensions（扩展型综合空气质量模型）<br>
**SMOKE**：Sparse Matrix Operator Kernel Emissions（稀疏矩阵算子内核排放处理系统，是将原始排放清单加工为时空分配并与化学机制匹配的、可供空气质量模型直接读取格式的关键预处理工具）<br>
**NAQPMS**：Nested Air Quality Prediction Modeling System（嵌套网格空气质量预报系统，是中国科学院大气物理研究所发展的具有自主知识产权的多尺度空气质量预报与成因分析模型）<br>
**RegAEMS**：Regional Atmospheric Environment Modeling System（区域大气环境模拟系统，通常指中国自主研发的、集成从排放到模拟全过程的区域空气质量综合建模系统）<br>
**AERMOD**：AMS/EPA Regulatory Model（美国气象学会/环保局法规模型，是国际通行的、基于稳态假设的法规级工业点源及面源环境影响评价模型）<br>
**CALPUFF**：California Puff Model（加利福尼亚烟团模型，是美国环保局推荐的、适用于复杂地形和长距离输送（可达数百公里）情景的拉格朗日烟团扩散模型）<br>
